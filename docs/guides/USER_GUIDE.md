# 🎮 德语学习助手 - 快速使用指南

## 🚀 立即开始

### 1. 启动应用
```bash
cd D:\german-learning-assistant
npm run dev
```

### 2. 打开浏览器
访问：http://localhost:3000

### 3. 选择模式

**传统模式** - 听力练习 + 拼写练习
- 🎧 听德语句子
- ✍️ 听写整句
- 📊 查看进度

**分词填空 ✨** - 全新体验（推荐！）
- 🎯 逐词输入
- ⌨️ 键盘快捷键
- 🎨 流畅动画
- 🔊 智能TTS语音

---

## ⌨️ 分词填空快捷键

| 快捷键 | 功能 |
|--------|------|
| `空格` / `Tab` | 跳到下一个输入框 |
| `Shift+Tab` | 返回上一个输入框 |
| `Enter` | 提交答案 |
| `Ctrl+P` | 播放德语语音 |
| `Ctrl+;` | 显示答案 |

---

## 🎯 使用流程

1. **选择水平**（A1-C2）
2. **点击"分词填空 ✨"**
3. **看到中文题目**
4. **逐个输入德语单词**
5. **按空格跳转**
6. **按Enter提交**
7. **查看反馈**（绿色=正确，红色=错误）

---

## 💡 提示

- **德语特殊字符**：可以输入 ae/oe/ue/ss 代替 ä/ö/ü/ß
- **标点符号**：自动处理，无需输入
- **重新开始**：随时可以点击"返回选择水平"
- **进度保存**：自动保存到浏览器本地
