# 🎧 德语播客下载指南

## 方法1：从DW网站直接下载（推荐）

### DW慢速新闻
1. 访问：https://learngerman.dw.com/de/langsam-gesprochene-nachrichten/s-60040332
2. 每个音频都有下载按钮
3. 下载后放到：`D:\german-learning-assistant\public\audio-downloads\`
4. 刷新浏览器 http://localhost:3003

### 其他DW播客
- 新闻：https://learngerman.dw.com/de/nachrichten/s-100953
- Top-Thema: https://learngerman.dw.com/de/top-thema/s-102267

### Easy German (强烈推荐)

## 方法4：已有音频文件

如果你有德语听力材料（课程音频、播客等）：
1. 直接复制MP3文件到：
   ```
   D:\german-learning-assistant\public\audio-downloads\
   ```
2. 刷新浏览器
3. 选择音频开始学习

---

## 💡 使用技巧

### 第一次听：
- 用正常速度（1.0x）完整听一遍
- 了解大意，不要纠结细节

### 第二次听：
- 用慢速（0.75x）逐句听写
- 使用后退5秒按钮重复

### 第三次及以后：
- 跟读练习，模仿发音
- 记录生词和短语

---

## 📁 文件位置

- **音频目录**: `D:\german-learning-assistant\public\audio-downloads\`
- **后端运行**: `npm run server` (端口3000)
- **前端访问**: http://localhost:3003
