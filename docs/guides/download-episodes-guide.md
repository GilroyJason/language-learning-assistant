# 📥 gPodder批量下载指南

## 在gPodder界面操作（推荐）

### 步骤1: 打开gPodder
```bash
D:\gpodder\bin\gpodder.exe
```

### 步骤2: 选择播客
点击左侧的 "DW - Langsam gesprochene Nachrichten"

### 步骤3: 全选episode
- 按 `Ctrl+A` 全选所有episode
- 或者手动勾选最新的几个

### 步骤4: 下载
- 点击工具栏的"下载"按钮
- 或右键 → "下载"

### 步骤5: 等待完成
- 下载进度会在底部显示
- 下载完成后会自动清理（保留最新10集）

## 自动下载设置（以后每次自动下载）

### 对每个播���启用自动下载：

1. 右键点击播客名称
2. 选择"设置"或"属性"
3. 勾选以下选项：
   - ✅ "下载新episode"
   - ✅ "下载策略" → "最新10集"
4. 点击"确定"

### 效果：
- gPodder每小时检查更新
- 发现新episode自动下载
- 自动删除旧的（保留最新10集）
- 自动删除已播放的
